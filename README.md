# 24 November 2026 — The World in One Image

One image summing up Tuesday 24 November 2026's world news: Iran's claim of
four tankers hit by mines in the Strait of Hormuz, the US jury finding Huawei
guilty on 10 counts, Ukrainian drone strikes on Russian ships, plus Senegal's
AFCON appeal win, the Turkish helicopter crash, the Cartagena hostages,
China's Shenzhou-24 crew, the Houthi advance on Aden, Nepal's 5.6 quake and
the Megaspeed blacklist in the Nvidia spy probe.

`main.ts` copies the image held in this repository to `/output/entry.png` —
no network, no clock, no randomness, so both runs write identical bytes.
